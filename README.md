# AI News Brief

AI News Brief is a concise daily dashboard for following important developments in artificial intelligence. The local MVP covers:

- major company and product updates;
- AI policy and regulation;
- new AI research; and
- AI education updates.

Each story includes its publication date, a short summary, why it matters, and a link to the original source. Stories can be filtered by category and saved locally in the browser.

## View the site locally

### Requirements

- Node.js 22.13 or newer
- pnpm

### Start the site

From this project folder, run:

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) in a browser.

## Current status

This is a local MVP with a manually curated daily edition. It does not use accounts, email subscriptions, a database, or automated news collection. The project has not yet been published to GitHub or deployed as a public website.
